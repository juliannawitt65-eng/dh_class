# Recording the Century: Media Formats, 1877–2006

An interactive TimelineJS timeline of 20th-century media formats, revised and expanded from a nine-entry class sample.

- **Live site:** https://juliannawitt65-eng.github.io/dh_class/media-timeline/
- `index.html` is the timeline page, with group filters and a plain list view
- `about.html` covers what changed, methods, ideas for the next version, and image credits
- `timeline.json` holds the timeline data (TimelineJS JSON format). Edit it to change entries
- `data/media-formats-revised.csv` has the same data in the Knight Lab Google Sheets template layout

Images are from Wikimedia Commons, and each slide credits its creator and license.
